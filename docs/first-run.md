# First run

The setup URL is an operator capability. Open it privately and do not paste it into tickets or chat.

The wizard covers:

1. What stays in `/data` and the single-household model.
2. Administrator display name and a 12+ character password, stored as Argon2id.
3. Locale, time zone, and base currency.
4. Household profile labels. Profiles are filters, not separate logins.
5. Enabled collections, including Pantry and Pets.
6. Wishlist, outfit ideas, and the optional public shop.
7. Manual entry, product URL import, or exploring an empty collection.
8. The exact backup command and a secret-free recovery guide download.

Setup commits once at the final step. Reloading before then is safe. After completion the setup token cannot reopen setup, even if the container environment changes.

Settings remains the home for branding, region, profiles, collections, features, shop copy, price privacy, and the dismissible getting-started checklist. Removing a profile is blocked until referenced items, outfits, and budgets are reassigned.
