# Security policy

Security fixes are provided for the latest stable release. Update to the newest published image before reporting an issue that may already be fixed there.

Report suspected vulnerabilities privately through GitHub Security Advisories for this repository. Include the affected version, deployment mode, reproduction steps, and impact. Do not open a public issue for an unpatched vulnerability and do not include real inventory, credentials, setup links, cookies, or backups.

The project will acknowledge a complete report within seven days and coordinate disclosure after a fix is available. See [docs/security.md](docs/security.md) for the supported threat model.
